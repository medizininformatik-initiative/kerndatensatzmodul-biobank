## Value Sets

> Short bridging text, newly written during the migration; the domain terminology notes are on the [Code Systems](code-systems.md) page.

The value sets of this module predominantly bind SNOMED CT codes (specimen type, container type, additives, body site, laboratory procedures) as well as Cell Line Ontology codes (growth type, modifications). The complete, automatically generated list of all value sets can be found in the [artifact overview](artifacts.md); the domain notes on SNOMED CT, SPREC and CLO are on the [Code Systems](code-systems.md) page.
