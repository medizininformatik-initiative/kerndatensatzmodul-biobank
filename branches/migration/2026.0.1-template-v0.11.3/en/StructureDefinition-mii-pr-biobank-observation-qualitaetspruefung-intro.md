### Content

An Observation resource represents quality checks that were performed, e.g. viability measurement, mycoplasma testing, STR analysis, re-thawability / return to culture.

### Examples

* Pass/fail check: [Qualitätsprüfung Buffy Coat](Observation-QualitaetspruefungBuffyCoat.html)
* Quantitative result: [Qualitätsprüfung Plasma](Observation-QualitaetspruefungPlasma.html)
