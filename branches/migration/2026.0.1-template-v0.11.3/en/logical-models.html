Logical Models

The official version of the information model for the core data set module biospecimen data is available here as a FHIR logical model: MII LM Biobank

Note that the logical model aims purely at representing the data elements and their descriptions. The data types used are not to be regarded as binding — that is conclusively determined by the FHIR profiles. For every element within the logical model there is a mapping to an element of a concrete FHIR resource:

Further specimen properties

In some cases it may be necessary to record further properties of a specimen, such as cell counts. The current version of the module makes no stipulations for this in the form of FHIR profiles, but modelling via the FHIR Observation resource is recommended. The specimen can be referenced in the focus field. SNOMED codes such as *118218001 Cell count (procedure) * can be used as codes. Future versions of this module may make further stipulations in this regard.
